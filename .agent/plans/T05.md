## Surprises & Discoveries

The public snapshot exposes sample text and labels. The scenario registry holds the expected answers. A normalized sample can have different whitespace inside its evidence quote, which must still be a verbatim span of the submitted text.

A fake client could fabricate the known SKU for an ambiguous message or quote a Thai booking request as incident evidence. Both regression cases initially returned incidents and now return clarifications.

## Decision Log

## Outcomes & Retrospective

The public response schema accepted the expected incident, warehouse clarification and ignore outcomes for the three stored samples. Running the hero message with two refusing clients returned the same offline incident and recorded both refusals.

With two unresponsive local clients and real timers, both attempts were aborted and the offline hero incident returned in 18,014 ms. Live OpenAI, the API route and its UI will be checked in their respective tasks.

## Starting point

`lib/scenarios/hero.ts` supplies the sample messages, warehouse names, shifts and fixed scenario date. `lib/domain/contracts.ts` defines the public interpretation response. The interpreter may return an incident, a clarification or ignore. It has no role in planning or booking.
