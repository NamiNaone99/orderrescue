## Milestones and steps

1. From the repository root, run `pnpm install --frozen-lockfile` and `pnpm exec playwright install chromium`. Write `playwright.config.ts`, `e2e/helpers.ts` and `e2e/home.spec.ts`. The smoke resets its selected scenario, loads `/` with HTTP 200 and checks for a nonempty title.
2. Add `.github/workflows/ci.yml` for pushes and pull requests. The job installs the locked package manager, caches pnpm dependencies, runs quality checks, installs Chromium and executes the smoke. Scan tracked files without printing possible credentials. Retain the HTML report when a check fails.

## Validation and acceptance

Run `pnpm lint`, `pnpm typecheck`, `pnpm test` and `pnpm e2e` from the repository root. Run `pnpm vitest run tests/security --passWithNoTests` after the build. Confirm the PR workflow succeeds and record its URL.
