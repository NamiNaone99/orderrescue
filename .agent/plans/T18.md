## Surprises & Discoveries

The provenance labels include `real_shifted` for order times and `opaque` for replacement customer references. Explain these transformations explicitly. T12 results expose separate numerators and denominators for each accuracy metric.

The Tailwind loader applied to all CSS imports in this repository, so the initial CSS module did not supply its class names. The mobile test exposed the resulting table overflow. A page stylesheet with scoped class names fixed the issue.
