# เกณฑ์ทดสอบก่อนค้นหลักฐาน
กำหนดวันที่ 21 พฤศจิกายน 2569 ตามเวลาไทย ขอบเขตคือผู้ค้าส่ง ผู้จัดจำหน่าย 3PL และร้านที่จัดส่งเองในไทย โดยใช้ SEA เป็นกรณีเทียบเคียง เกณฑ์ตัวเลขด้านล่างเป็นสมมติฐานเพื่อการตัดสินใจของการศึกษานี้ ความมั่นใจต่ำ และใช้กับกลุ่มนำร่องเท่านั้น

| ข้อ | เงื่อนไขที่หักล้างสมมติฐาน |
| --- | --- |
| H1 | ในกลุ่มเป้าหมาย ค่ามัธยฐานเหตุภัยพิบัติที่ทำให้ออเดอร์ผิดนัดต่ำกว่า 1 ครั้งต่อบริษัทต่อปีในบันทึกย้อนหลัง 3 ปี หรือมูลค่าผลกระทบต่อปีต่ำกว่าเกณฑ์ที่ผู้อนุมัติงบกำหนด |
| H2 | ในออเดอร์ผิดนัดหรือยกเลิก สาเหตุที่แก้ได้ด้วยการระบุผลกระทบหรือหาแหล่งสต็อกเร็วขึ้นมีสัดส่วนต่ำกว่า 50% โดยวัดหลังตรวจข้อจำกัดเส้นทาง สิทธิ์ และรอบรถ |
| H3 | ค่ามัธยฐานของออเดอร์กระทบที่มีสต็อกพร้อมจองซึ่งใช้แทนได้และส่งทันต่ำกว่า 20% หรือบัญชีที่ผ่านเงื่อนไขมีน้อยกว่าที่ต้องใช้เพื่อคุ้มต้นทุนการเข้าตลาด |
| H4 | ขั้นตอนเดิมใช้เวลาคนและสร้างความสูญเสียต่ำกว่าต้นทุนรวมของระบบ หรือผู้อนุมัติงบที่เห็นผลจากข้อมูลจริงไม่รับข้อเสนอทดลองแบบชำระเงิน |
| H5 | ระบบเดิมทำงานกรณีเดียวกันได้ครบตาม SLA และกฎธุรกิจ และต้นทุนเปิดใช้รวมต่ำกว่าข้อเสนอ OrderRescue |
| H6 | ในเคสที่เปรียบเทียบกันได้ อัตรารับข้อเสนอส่งใหม่/ช้า/แยกไม่สูงกว่าการปิดออเดอร์ด้วยการยกเลิกตามเกณฑ์ลูกค้ากำหนด หรือกำไรส่วนเพิ่มหลังคืนสินค้าและค่าใช้จ่ายไม่เป็นบวก |
| H7 | มูลค่าเพิ่มสุทธิต่อบัญชีไม่ครอบคลุมต้นทุนรวมฝั่งลูกค้า หรือจำนวนบัญชีที่ยอมจ่ายคูณกำไรส่วนเพิ่มต่อบัญชีไม่ครอบคลุมต้นทุนคงที่ฝั่งผู้ขาย |
