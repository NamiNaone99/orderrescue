# บันทึกการตรวจหลักฐาน · OrderRescue

- ขอบเขต Deep Dive สำหรับประเทศไทย อ้าง SEA และต่างประเทศเพื่อเทียบกลไก เกณฑ์ H1–H7 ถูกบันทึกก่อนค้นที่ [Kill Criteria](kill-criteria.md)
- ตรวจแหล่งถึง 21 พฤศจิกายน 2569 ตามเวลาไทย ครอบคลุมผลกระทบ ประกันภัย โครงสร้างตลาด สาเหตุและลูกค้า คู่แข่ง และหลักฐานออกแบบ Agent ตำแหน่งที่อ่านและการเข้าถึงอยู่ในการ์ด
- ตรวจตัวเลข DaLA และรอบค่าสินไหม ภาพหาดใหญ่จากรายงาน ธปท. สองชุด มาตรการน้ำท่วมของ TikTok โครงสร้างสถานประกอบการ NSO ฟังก์ชัน Shopify และ SAP Learning รวมถึงผลการยกเลิกที่ Freedom รายงานผ่านผู้ขาย ใช้หลักฐานผู้ขายเฉพาะขอบเขตฟังก์ชันที่เผยแพร่และผลของเคสที่ระบุ
- คำนวณโมเดล loss และกรอบ TAM/SAM/SOM ใหม่จากสมมติฐาน ตรวจจำนวนบริษัท รหัสแหล่งและลิงก์ภายใน แยกรายได้จากกำไรและผลประโยชน์ของลูกค้าจากค่าบริการสมมติ
- ช่องว่างที่ยังเปิดคือความถี่เหตุจริงในบัญชีเป้าหมาย จำนวน SKU ทดแทนที่พร้อมจอง ความแม่นของสต็อก มูลค่าที่กู้เพิ่มเทียบวิธีเดิม และราคาที่อนุมัติจ่าย ดูการทดสอบและคำถามใน [รายงานหลัก](report.md)
