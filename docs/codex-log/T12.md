## Human corpus handoff

The default file check validates every record, exact source conversion, evidence substrings, unique IDs, both splits and starter integrity. `pnpm eval:check-corpus` additionally requires coverage of all seven specified categories. The starter covers clear, ambiguous and irrelevant. **Contradictory, typo or slang, multi-SKU, and out of scope or injected instruction** each have zero cases.

An editor can provide new human-authored, independently checked TSV entries, run `pnpm eval:rows` and rerun `pnpm eval:check-corpus`. An optional `scenario` column overrides the default `real-day`. All input messages and labels are preserved, including literal whitespace. Blank cells become null; nonempty SKU cells split on commas.

Live evaluation is reserved for a human. The CLI accepts `--live`, `--split dev|heldout|all` and `--limit n`. A live run announces its estimated API call count, processes rows sequentially through the existing two-attempt chain, and emits an offline comparison. Missing scenarios appear in the output and trigger a nonzero exit. Live held-out threshold misses also trigger a nonzero exit. Incomplete corpus runs keep the published AC-26 field unverified.
