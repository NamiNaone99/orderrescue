# T04 store interface and in-memory atomic booking

21 Nov 2026, 11:10 ICT · Local Windows workspace · gpt-6.2-astra

Implemented the server-side Store interface, typed errors and the global in-memory adapter. T04 started from `main` at `882f72c`, after T03 PR #1 merged. The T03 head passed local checks and a production build. GitHub had zero configured Actions workflows.

The transaction looks up the idempotency key before checking the budget and the orders. It groups confirmed lines by stock row, validates each group and publishes one replacement snapshot. Reads and receipts are detached from the stored data. Versions cover all stock revisions and order statuses, including when a read is filtered.
