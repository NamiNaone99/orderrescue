[README ภาษาไทย](../../README.md) เป็นหน้าแรกของคลัง ส่วน [English README](../../README.en.md) มีเนื้อหาครบชุดเดียวกัน สองหน้าเชื่อมถึงกันจากบรรทัดแรกหลังชื่อโครงการ ผู้ชมเปิดโต๊ะจัดส่งหรือเดโมพร้อมบทพูดได้โดยตรง หน้าภาษาไทยเก็บชื่อจุดเชื่อมเดิม เช่น `#open-review-findings` เพื่อให้ลิงก์จากรายงาน T22 ยังใช้ได้
